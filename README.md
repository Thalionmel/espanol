## How practice works

Initiate active Spanish practice during ordinary work chats without waiting for a lesson request. Offer a 30–60 second unit early, normally within two normal work replies, and continue about every two to three suitable exchanges. Each unit has one objective and at most one optional production or recall prompt, followed by concise feedback and later reuse of corrections. An isolated translated phrase is insufficient. Defer during urgency or an explicit request for uninterrupted focus and honor English-only requests and skipped topics. Work continues without waiting for an answer; an ignored prompt creates no backlog. Saved instructions do not prove adoption by other chats.

Use independent, optional units of about 30–60 seconds during normal work.
Longer lessons, such as a five-minute session, happen on request.
Each unit introduces or reviews one pattern, with a short example and at most one optional prompt.
“Skip this” drops the current exercise; “skip this topic” deselects that topic until the learner opts back in.
An unanswered prompt creates no backlog. Review happens during suitable conversations; no scheduled reminders are set up.

Read the latest record at lesson/chat start, then keep practice flowing using the current conversation.
Save progress in batches after about 6–10 learning exchanges, or at lesson end, a topic change, or an explicit save request.
Refresh affected remote files before each batch save; routine exercises do not trigger individual repository updates.
Use recent corrections and spaced recall to select the next unit.
Keep examples connected to real work while recording only language-learning evidence.
This public repository excludes unrelated work contents and personal circumstances.

No application, dependency installation, server, or deployment is needed to use these records.
